정상파 실험실

역학과 에너지 Ⅲ · 16 정상파와 악기 — 다섯 가지 실험을 직접 조작해 보세요

1. 정상파 형성 실험

진동수·진폭이 같은 두 파동이 반대 방향으로 진행해 겹치면 어떻게 되는지 관찰한다.

오른쪽으로 가는 파동왼쪽으로 가는 파동합성파(정상파)마디배

조작판

측정값

v = fλ · 정상파 최대 진폭 = 2A · 마디–마디 = λ/2

관찰 포인트

  • ‘+ T/4 진행’을 눌러 보자. 최대 → 일직선 → 뒤집힌 최대 → 일직선 → 처음 모양이 반복된다.
  • 일직선인 순간에도 빨강·파랑 파동은 그대로 있다. 합쳐진 변위만 0이다.
  • 마디(초록 점)와 배(주황 점)는 시간이 지나도 제자리에 있다. 마디 사이 간격은 λ/2이다.
  • 정상파의 파장·진동수는 원래 파동과 같고, 배의 진폭은 2A이다.

2. 현악기 정상파 형성 실험

양 끝이 고정된 줄을 진동시켜 정상파를 만든다. 양 끝은 항상 마디이다.

화면의 진동은 실제보다 느리게 보여 준다

조작판

진동 배수 n (= 배의 개수)

측정값

L = (λ/2)·n → λₙ = 2L/n, fₙ = v/λₙ = (v/2L)·n
고유 진동수 (누르면 그 진동수로 맞춘다)

관찰 포인트

  • ‘입사파·반사파 보기’를 켜면 왼쪽에서 들어간 파동(파랑)이 오른쪽 끝에서 고정단 반사되어 뒤집힌 채 돌아오고(보라), 둘이 겹쳐 정상파(빨강)가 만들어지는 과정이 처음부터 천천히 보인다. 끝에서는 늘 상쇄 → 마디.
  • 고리(배) 개수 = n. 고리 하나가 반파장이므로 λ = 2L/n이다.
  • 줄 길이만 바꾸면 줄의 파동 속력 v는 그대로이다. 장력이나 줄 종류를 바꾸면 v가 바뀐다.
  • 진동수 조절 모드에서 고유 진동수에 맞을 때만 크게 진동한다(공명). 사이 값에서는 거의 진동하지 않는다.
  • 소리의 진동수는 줄의 진동수와 같지만, 공기 중 소리의 파장은 340 ÷ f로 줄의 파장과 다르다.

3. 개관 악기 정상파 형성 실험

양쪽 끝이 열린 관. 열린 끝은 공기가 가장 크게 움직이는 배가 된다.

조작판

진동 배수 n

측정값

L = (λ/2)·n → λₙ = 2L/n, fₙ = (V/2L)·n (n = 1, 2, 3, …)
고유 진동수

관찰 포인트

  • ‘입사파·반사파 보기’를 켜면 왼쪽에서 들어간 음파(파랑)가 오른쪽 열린 끝에서 자유단 반사되어 그대로 돌아오고(보라), 둘이 겹쳐 정상파(빨강)가 만들어지는 과정이 보인다. 열린 끝에서는 보강 → 배.
  • 양 끝이 모두 배이다. 기본 진동은 가운데에 마디 하나 → λ = 2L.
  • n = 1, 2, 3, … 모든 정수 배수가 생긴다. 같은 길이의 줄과 파장 관계가 같다.
  • 온도를 올리면 음속 V가 커져 같은 n에서 진동수가 높아진다. 파장은 관 길이로 정해지므로 그대로이다.

4. 폐관 악기 정상파 형성 실험

한쪽 끝이 막힌 관. 열린 끝은 배, 막힌 끝은 공기가 움직이지 못하는 마디가 된다.

조작판

진동 배수 n (홀수만 가능)

측정값

L = (λ/4)·n → λₙ = 4L/n, fₙ = (V/4L)·n (n = 1, 3, 5, …)
고유 진동수

관찰 포인트

  • ‘입사파·반사파 보기’를 켜면 왼쪽에서 들어간 음파(파랑)가 오른쪽 막힌 끝에서 고정단 반사되어 뒤집힌 채 돌아오고(보라), 둘이 겹쳐 정상파(빨강)가 만들어지는 과정이 보인다. 막힌 끝은 마디, 열린 끝은 배.
  • 배에서 시작해 마디로 끝나므로 반 고리(λ/4) 단위로 센다. 기본 진동 λ = 4L.
  • 반 고리가 홀수 개여야 하므로 n = 1, 3, 5, …만 생긴다. 진동수 조절 모드에서 2f₁ 근처를 지나도 공명하지 않는다.
  • 같은 길이의 개관과 비교하면 기본 진동수가 절반 → 한 옥타브 낮은 소리.

5. 기주 공명 실험

소리굽쇠를 울리면서 물통을 내려 수면 위치를 바꾼다. 소리가 크게 들리는 위치를 기록해 파장과 음속을 구한다.

조작판

소리 세기

기록표

순서y (cm)이웃 차 Δyλ = 2Δy

관찰 포인트

  • 관 입구는 배, 수면은 항상 마디이다. 공명할 때마다 정상파가 반파장씩 늘어난다.
  • 소리가 크게 들리는 위치 사이 간격 = λ/2. 그래서 λ = 2(yₙ₊₁ − yₙ), v = 2f(yₙ₊₁ − yₙ).
  • 첫 위치 y₁은 λ/4보다 조금 짧다. 관 입구 바깥에 배가 생기기 때문(끝 보정)이다. 그래서 차로 계산한다.
  • 같은 소리굽쇠면 몇 번째 공명이든 들리는 소리의 진동수는 같다.

6. 고정단 반사와 자유단 반사

펄스 하나를 끝으로 보내 반사되는 모습을 천천히 비교한다. 아래에서는 굵은 줄과 가는 줄을 이어 연결점에서의 반사와 투과를 본다.

관찰 포인트

  • 고정단 반사: 끝이 움직이지 못한다 → 반사파가 뒤집혀서(위상 반대) 돌아온다. 끝에서는 입사파와 반사파가 항상 상쇄 → 마디.
  • 자유단 반사: 끝이 자유롭게 움직인다 → 반사파가 그대로(같은 위상) 돌아온다. 끝에서는 보강 → 배.
  • 줄의 양 끝·폐관의 막힌 끝은 고정단, 관의 열린 끝은 자유단이다(공기의 진동 변위 기준).
  • 반사파의 속력·파장·진동수는 입사파와 같다. 바뀌는 것은 뒤집히는지(위상)뿐이다.
  • 가는 줄 → 굵은 줄: 연결점이 잘 안 움직여 고정단 반사처럼 반사파가 뒤집힌다. 굵은 줄로 넘어간 투과파는 느려져 폭(파장)이 좁아진다.
  • 굵은 줄 → 가는 줄: 연결점이 쉽게 움직여 자유단 반사처럼 반사파가 그대로 돌아온다. 가는 줄로 넘어간 투과파는 빨라져 폭(파장)이 넓어진다.
  • 투과파는 어느 경우에도 뒤집히지 않는다. 줄이 바뀌어도 진동수는 그대로이고, 속력과 파장만 바뀐다.
화면의 진동 속도는 관찰하기 쉽게 늦췄다. 소리 켜기를 누르면 실제 진동수의 소리가 세기에 맞춰 난다.
